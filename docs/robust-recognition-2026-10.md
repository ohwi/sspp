# 창 크기와 그림 정렬 보정: 1.1.0-dev7

창 폭 960·1024·1280·1366·1600·1920·2560의 기본 카드 조건에서, 그림으로 구분 가능한 **8,890건 모두 정답**이었다. 동일한 그림의 70건은 별도로 보류했다. 기존 실제 사진 16장을 원본·7개 폭·3개 검은 여백·늘림 조건으로 재생한 **576개 카드도 얼굴·잠재력·목표·우선순위가 모두 정답**이었다. 기존 1366px의 513906→513905 오확정은 교정됐다.

## 변경

- 관측한 색상 배경으로 카드 위치와 크기를 잡고, 그 좌표를 기준으로 배경색과 도형을 판정한다. 큰 그림의 정렬은 도형 창을 움직이지 않는다.
- 그림만 90~110%로 바꾸는 제한된 크기 탐색과 위치 탐색을 추가했다. 역할별 후보 16개·목표 0·색상·배경·그림·도형·후보 간 점수 차이·동일 이미지 보류 조건을 유지한다. 기존 기준값을 단순히 낮춘 변경은 아니다.
- 기존 강한 확정과 신경망 확정은 유지한다. 낮은 점수의 기존 확정은 전체 후보를 통한 관측 배지의 신경망 판정으로 재확인한다. 새 정렬에서 명확한 대체 결과 또는 동일 이미지·경쟁 충돌이 확인되면 바꾸며, 정렬 증거가 부족한 경우 기존 경로를 유지한다.
- 실제 대칭 검은 여백과 16:9 내용 영역을 픽셀로 확인한 경우 캡처와 오버레이 좌표를 함께 바꾼다. 비율만 보고 여백을 가정하지 않는다. 여백 없는 다른 비율은 두 정규화 결과의 얼굴 증거를 비교하고, 확실한 개선이 있을 때만 대안을 선택한다.
- 창 이동·크기 변경 시 영역을 다시 확인한다. 동일 창 좌표의 여백 관측은 1초 캐시를 사용한다.
- 모니터별 DPI 선언을 실행 파일에 포함하고 Qt가 물리 픽셀 좌표를 사용하도록 시작 시 이 앱의 환경만 정리한다. 부모 프로세스와 Windows 표시 배율 설정은 바꾸지 않는다.
- 전체 고정 DB 40명·1,160개 잠재력에 보정 메타데이터를 등록했다. 신경망은 기존 약82KB·21,060개 파라미터 그대로이며 재학습하지 않았다. 얼굴 이미지는 기존 33명이다.

## 남은 범위

미인식 1,247건은 배경과 도형을 고정한 채 **그림만 105% 또는110%로 확대·이동한 4개 추가 스트레스 조건**에서 발생했다. 창 전체 크기를 바꾼 조건의 실패는 아니다. 전체 independent 비율을 이전 91.7%와 직접 비교하면 변형 범위가 달라 오해가 생긴다.

동일 그림인 역할 내 5쌍은 그림만으로 ID를 구분할 근거가 없어 보류한다. 정답 ID를 추론에 주거나 목표 0 후보를 제외하지 않았다. 일부 탈색 검사는 첫 전용 카드만 다뤘으며 모든 카드의 탈색을 전수 검사한 결과는 아니다.

실사진 결과는 이미 살펴본 3캐릭터·16장의 내부 회귀 자료를 변환한 결과다. 새로운 사진, 실제 40명 얼굴·스킨, 혼합 DPI 모니터를 이동하는 실기 검증은 남아 있다. 얼굴 미등록 7명은 chaton·eleanor·firefly·karin·otoha·sparkla·wraith다. 공개 DB의 40명 범위가 현재 실제 서버 전체를 입증하는 것은 아니다.

이 실험은 동일한 공개 원본을 사용하되 별도 보간 구현으로 입력을 만든 카드 단계 검사다. 신경망만의 기여 또는 독립 시행 확률을 추정하지 않는다. 확대 스트레스는 1280px에서 균형 부분 집합800개로 시행했고, 창 폭과 그림 변형의 모든 교차 조합을 전수 검사하지 않았다.

## 재현과 기록

```powershell
.\.venv\Scripts\python.exe scripts/benchmark_robust_potentials.py --app-dir app --run-label new-dev7-test --source-label dev7
```

원본 합성 캐시와 r3 자료는 이전 합성 검증 문서의 작업 구조를 사용한다. 기존 결과를 덮어쓰지 않는 새 출력 이름이 필요하다. 모델 SHA256은 `3624d9cb8ff164f790ee89bdb0afdc6fcced5d22f3886c22ecd8f1883fceb12f`, full 보고 SHA256은 `c4449c16cd17077cba7419384c85ed2a566ef639ee26501e740aab17ce2d3fa2`다.

합성 평가가 끝난 후 시작 파일의 Qt 좌표 환경과 빌드 경로를 마무리했다. 최종 패키지 검사에서 평가한 인식 코드·모델·모든 카드의 픽셀과 meta가 배포본과 일치하는지 별도로 확인한다. 최종 실행 파일은 사용자 화면을 띄우지 않고 시작·모델·리소스 로딩을 검사한다. 실제 게임 입력은 하지 않는다.

DPI 참고: [Windows 프로세스 기본 DPI 설정](https://learn.microsoft.com/en-us/windows/win32/hidpi/setting-the-default-dpi-awareness-for-a-process), [Qt5의 표시 배율](https://doc.qt.io/archives/qt-5.15/highdpi.html). Qt5에서 외부 배율 변수만으로 좌표가 달라지는 반례를 자식 프로세스에서 관측했고, 앱 범위의 배율 정리 후 강제 변형4개에서 현재 두96DPI 화면의 Qt/native 좌표가 일치했다. 이것은 실제125/150% 모니터 이동 검증이 아니다.
