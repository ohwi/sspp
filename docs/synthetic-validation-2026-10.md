# 전체 잠재력 합성 검증: 2026-10-12

고정된 현재 DB의 **40명·1,160개 잠재력**을 합성하고, dev6 모델과 기준값을 바꾸지 않은 채 **13,120건**을 검사했다. 독립 합성 변형 중 구분 가능한 11,430건은 **정답 10,483건(91.715%)·오확정 0건·미인식 947건**이었다. 같은 역할에서 시각 정보가 동일한 5쌍은 별도로 검사해 90건 모두 보류했다.

캐릭터를 미리 지정한 카드 인식 검사다. 전체 캐릭터의 실제 게임 인식이 검증됐다는 뜻은 아니다. 합성 후보는 검증 폴더에만 저장했으며 앱에 등록하지 않았다.

## 주요 결과

|---|---:|---:|---:|---:|

미인식 947건 중 **904건(95.46%)**은 배경과 도형을 그대로 두고 큰 그림만 5% 줄여 오른쪽 3px·위쪽 2px 이동한 조건에서 발생했다. 창 전체 크기를 바꾸는 조건과는 다르다. 나머지 43건은 카드 우측과 하단의 2px을 검게 가리고 잡음을 더한 인위적 조건에서 발생했다. 실제 클라이언트가 이 변형을 적용한다는 증거는 없다.

947건을 고정된 매처로 다시 읽었을 때 모두 같은 낮은 점수로 보류됐고, 경량 신경망 호출은 0건이었다. 일반 카드 600건은 그림 일치 점수가 0.548~0.798로 신경망 복구 진입 기준 0.80에 미달했다. 나머지 347건은 도형이 없는 전용 카드여서 현재 배지 신경망의 적용 대상이 아니다. 배경 색상은 정상 범위였다. 다음 개선 대상으로 그림의 크기·위치 차이를 다루는 정렬을 검토할 근거다.

## 검사 방법과 범위

- 공개 원본 446개를 고정 Git blob과 SHA로 확인했다. 큰 그림 433개 경로는 서로 다른 이미지 430개에 해당한다. 실제 신경망 학습에 사용한 그림 39개와 미사용 394개 경로(391개 이미지)를 구분했다. 도형 자체는 기존 3종을 공유하므로 새 도형 종류의 일반화 검사는 아니다.
- 후보 생성은 기존 r3의 배경·그림·도형 변환을 사용했다. 검사 입력은 별도로 작성한 NumPy 역방향 보간·알파 합성으로 원본층을 조합했다. 생성 이미지 그대로를 읽는 복사 대조군 1,280건은 정확도 분모에서 제외했다.
- 게임 코드 형식으로 메인·지원 프리셋 80개를 인코딩한 뒤 실제 importer와 BuildLoader를 거쳐 각 16개 후보를 확인했다. 목표 0도 포함했다. 공통 잠재력이 두 역할에 등장하므로 1,160개 ID는 1,280개 역할 사례가 된다.
- 실제 MatcherWorker.detect_skill이 이미지를 읽고 판정했다. 캐릭터와 역할은 검사 문맥으로 지정했다. 정답 PID·기대 도형·생성 좌표를 추론에 주지 않았다. 얼굴과 실시간 UI를 포함한 앱 전체 평가는 아니다.
- 결과를 보기 전에 seed 20261012와 9개 변형을 고정했다. 재학습과 기준 완화는 하지 않았다. 모델 가중치 SHA256은 `3624d9cb8ff164f790ee89bdb0afdc6fcced5d22f3886c22ecd8f1883fceb12f`다.

복사 대조군은 정답 1,270건·동일 그림 보류 10건이었다. 안전 대조군 320건은 전부 보류했다. 각 80개 문맥의 검정·회색·흰 빈 화면과 첫 전용 카드의 탈색을 검사했다. 일반 카드의 모든 탈색 변형을 전수 검사한 결과는 아니다. 오확정 0건은 이번 유한한 자료에서 관측한 결과다.

모든 정답의 실제 목표 레벨은 보존됐다. 독립 변형의 목표 0 정답 2,403건도 포함한다. CSV에 실제 priority 열이 없어 전체 합성 사례의 우선순위 전달까지 검증한 결과로 표현하지 않는다.

기존 실제 스크린샷 16장을 전체 후보 라이브러리로 다시 읽었을 때 **48개 카드 모두 정답**이었고, PID·점수·목표·우선순위도 dev6 결과와 같았다. 이 사진은 앞서 문제 발견에 사용한 3캐릭터·31종의 내부 회귀 자료다. 새로운 사진이나 전체 40명의 얼굴·스킨·실시간 오버레이 검증은 남아 있다.

## 다음 판단

기존 앱 이미지·모델·매칭 기준은 유지했다. 이번 실험은 경량 신경망만의 기여를 분리해 측정하지 않는다. 먼저 보완할 부분은 큰 그림의 크기와 위치 차이를 다루는 인식 경로다. 같은 역할에서 시각 정보가 동일한 5쌍은 현재 공개 원본의 그림만으로 ID를 구분할 근거가 없으며, 이름 텍스트 같은 추가 증거가 필요하다.
