# Potential Planner

게임 '스텔라 소라' 화면을 실시간으로 분석하여 캐릭터를 인식하고, 프리셋의 잠재력 목표 레벨 또는 빌드의 고정 우선순위를 카드 위에 표시해 주는 도구입니다.

이 브랜치의 **1.1.0-dev7은 게임 잠재력 프리셋 가져오기와 창 크기·그림 정렬 보정을 포함하는 개발 버전**입니다. 960~2560px의 7개 창 폭에서 구분 가능한 합성 카드가 모두 정답이었고, 기존 실제 사진의 크기·비율을 바꾼 576카드도 모두 정답이었습니다. 전체40명·잠재력1,160개에 보정 메타데이터를 적용했으며 얼굴 이미지는33명입니다. 그림만105~110%로 바꾼 추가 스트레스에는 미인식1,247건이 남습니다. 새 실사진·모든 얼굴·혼합DPI 실사용 검증은 남아 있습니다. [보정 결과와 범위](docs/robust-recognition-2026-10.md), [경량 모델](docs/lightweight-recognition-2026-10.md), [프리셋 규격](docs/ingame-presets.md)을 확인하세요.

## 주요 기능

### 실시간 화면 인식
* MSS와 OpenCV를 활용한 고속 화면 스캔
* 캐릭터 얼굴 식별 후 스킬 이미지를 대조하는 2단계 매칭 시스템 적용

### 스마트 오버레이
* 게임 프리셋 목표 1~2는 'Lv.1 확보', 3~5는 '다다익선', 6은 '목표 Lv.6', 0은 '목표 제외'로 표시
* 추천 등급(Essential, Lv.6, Lv.1)에 따른 색상별 테두리 표시
* Click-through(클릭 투과) 지원으로 오버레이가 활성화된 상태에서도 게임 조작 가능

### 게임 잠재력 프리셋 가져오기 (v1.1.0-dev4)
* 게임에서 복사한 프리셋 코드를 붙여넣어 메인·서포트 캐릭터와 잠재력 목표 레벨을 로드
* Lv.2·Lv.3을 포함한 원래 목표 레벨과 목표 제외 값을 보존
* 가져오기 결과에 한국어 잠재력 이름과 목표 해석을 표시하고, 해석과 원본 값이 다른 Lv.2 및 다다익선의 원본 Lv.3~Lv.5도 병기
* 인식 이미지가 부족하면 안내
* 현재 획득 레벨이나 목표까지 남은 횟수는 아직 읽지 않음

### SSToy 웹 빌드 연동
* 외부 공략 사이트의 빌드 URL을 입력하여 캐릭터 잠재력 및 스킬 우선순위 데이터 로드 기능
* JSON 파일을 직접 수정하지 않고 최신 메타 반영 가능

### 해상도 자동 대응
* 게임 창 크기 및 해상도 변경 시 상대 좌표 비율(Ratio) 계산을 통해 인식 위치 자동 추적

### 디버그 모드
* 인식 범위(ROI) 및 이미지 일치율(Score) 시각화 기능 제공

## 다운로드 및 실행

### 1. 설치
1. 이 개발 브랜치에는 아직 GitHub Release가 없습니다. 아래 소스 실행·빌드 방법을 사용합니다. 기존 배포본은 [원본 Releases](https://github.com/haenir74/Stella-Sora-Potential-Planner/releases)에 있습니다.
2. 압축을 해제합니다. (모든 파일은 실행 파일과 같은 폴더에 유지되어야 합니다.)

### 2. 실행 방법
1. 게임 클라이언트를 실행합니다.
2. PotentialPlanner.exe를 실행합니다.
3. 빌드를 선택합니다.
    * 방법 A: 드롭다운 메뉴에서 저장된 JSON 파일 선택
    * 방법 B: '프리셋 가져오기 (+)' → '게임 잠재력 프리셋 코드'에서 게임의 공유 코드 입력
    * 방법 C: 같은 창에서 'SSToy 빌드 URL'을 선택하여 공략 사이트 주소 입력
4. 재생(▶) 버튼을 눌러 인식을 시작합니다.

## 🛠️ 개발 환경 설정 (For Developers)

이 섹션은 소스 코드를 직접 수정하거나 기능을 추가하려는 개발자를 위한 안내입니다.

### 1. 필수 요구 사항
* Python 3.10 이상 (개발 검증: Python 3.11)
* Windows OS (WinAPI 의존성)

### 2. 설치 및 실행
저장소 루트에서 다음 명령을 실행합니다.
```powershell
py -3.11 -m venv app/.venv
.\app\.venv\Scripts\python.exe -m pip install -r app/requirements.txt
.\app\.venv\Scripts\python.exe app/run.py
```

가상환경을 루트의 `.venv`에 만드는 경우에도 같은 Python으로 실행할 수 있습니다.

### 3. 프로젝트 빌드
`app/.venv`에 빌드 의존성을 설치한 뒤 `app/build.bat`을 실행합니다.
```powershell
.\app\.venv\Scripts\python.exe -m pip install -r app/requirements-build.txt
.\app\build.bat
```

결과물은 `PotentialPlanner_Build/dist/PotentialPlanner/`입니다. 실행 파일과 리소스 폴더를 함께 배포합니다. 기존 프리셋을 유지하려면 별도 폴더에서 새 개발 버전을 실행하세요.
